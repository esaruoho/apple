# HomePod climate sensor


[← Back to home](./)
HomeKit thermo-hygrometer read via `shortcuts run "HomePod Sensors"` every 15 min (quarter-hour aligned). The watcher runs 24/7 on **CloudcityMacMini**; output lands in the Syncthing comms share so any joined Mac reads the same live JSONL stream — no SSH, no port-forward, no laptop-side server.

## Canonical layout (2026-05-21)

```
CloudcityMacMini (writer, 24/7)              Any joined Mac (reader)
─────────────────────────────                ──────────────────────
~/work/homepod-watcher/                      ~/work/apple/homepod/
  homepod-climate.sh   (writer)                climate-graph.html  (dashboard, file:// works)
  climate-server.py    (:3007, optional)       climate-logs/       (symlink → share)
  climate-logs/        (symlink → share)
                                             ~/work/comms/queue/homepod-climate/
                                               <YYYY-MM-DD>.jsonl
                                               climate-data.js   (today, for <script>)
                                               climate-all.js    (all-time, for file://)
```

Both Macs see identical files under `~/work/comms/queue/homepod-climate/` via Syncthing. The writer's data dir and the laptop dashboard's `climate-logs/` are both symlinks into the share — writer code unchanged.

## Reusable patterns this established

1. **Symlink writer data into a Syncthing share** — two `mv`+`ln` lines turn any data-producing service on macmini into a two-machine-transparent service. Writer code unchanged.
2. **`climate-all.js` zero-server dashboard** — browsers block `fetch()` of sibling files over `file://`, but `<script src=>` works. Serve multi-file aggregates as a single `window._all = [...]` JS regenerated by the writer each tick.
3. **Lock locale in any bash JSON writer** — `export LC_ALL=C LC_NUMERIC=C` near the top. Without it, fi_FI locale leaks decimal commas (`"temperature_cal":22,55`). The homepod-watcher repo silently corrupted 49 JSONL files between 2026-03-04 and 2026-05-21 because of this.
4. **Quarter-hour alignment** for HomeKit/Shortcuts polling (`:00 :15 :30 :45`), with the WAIT=0 tight-loop bug guarded (commit `c573c4d`).
5. **Launch from Cloudcity-Boot.app pane, not LaunchAgent** — FileVault blocks LaunchAgents pre-login. The watcher runs as a child of `start.sh` in an iTerm pane.

## Calibration

Measured 2026-02-13 against a professional olosuhdemittaus sensor:

- Temperature: HomePod reads `0.45 °C` low → calibrated = raw + 0.45
- Humidity: HomePod reads `4.5 %` low → calibrated = raw + 4.5

Always use the calibrated fields (`temperature_cal`, `humidity_cal`).

## Reference consumer

`topbar/AppleToolbox.swift` (`climateRead`) — tails the synced JSONL on whichever Mac it runs on; identical code path on both machines.
